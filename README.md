# Шифратор-дешифратор (WPF)

Простое десктопное приложение для шифрования и дешифрования текста с поддержкой авторизации и работы с файлами.

## Описание проекта

Приложение позволяет:
- **Шифровать** и **дешифровать** текст с использованием алгоритма Цезарь.
- **Загружать** текст для обработки из внешнего `.txt` файла.
- **Сохранять** результат в текстовый файл.
- **Авторизовываться** в приложении для разграничения доступа.

Проект выполнен как учебное приложение для демонстрации основ работы с WPF и криптографией.

## Основной функционал

### Авторизация
- Вход по логину и паролю.

### Работа с текстом
- Ввод текста вручную в текстовое поле.
- Загрузка текста из файла (формат `.txt`).
- Отображение результата шифрования/дешифрования.
- Сохранение результата в файл.

### Шифрование и дешифрование

Используется **шифр Цезаря** с фиксированным сдвигом:

- **Шифрование:** каждый символ текста сдвигается на **22 позиции** вперёд по таблице Unicode.
- **Дешифрование:** каждый символ сдвигается на **22 позиции** назад.
